# Apex Investment Portfolio

The Apex Investment Portfolio is an automated investment service that charges a fee of 0.25 percent of assets per year.
There is no minimum balance required to open an Apex Investment Portfolio account.
The Apex Investment Portfolio automatically rebalances the portfolio back to target allocation quarterly.
Tax-loss harvesting is automatically applied to taxable Apex Investment Portfolio accounts.
Investors can adjust risk level from conservative to aggressive with four preset profiles.
Withdrawals from the Apex Investment Portfolio are processed within three business days.
Dividend reinvestment is enabled by default for all Apex Investment Portfolio accounts.
The Apex Investment Portfolio invests primarily in low-cost exchange-traded funds.

# Cloud Rewards Program

The Cloud Rewards Program awards one point per dollar spent on qualifying purchases.
Points under the Cloud Rewards Program can be redeemed for statement credit, travel, or gift cards.
Redeeming 10,000 Cloud Rewards points provides a $100 statement credit.
Points earned under the Cloud Rewards Program never expire while the account remains open.
Bonus categories rotate quarterly with 3 points per dollar on eligible spending.
Primary and authorized cardholders earn points into the same Cloud Rewards Program balance.
Cloud Rewards points take one to two billing cycles to post to the account.
Gift card redemptions start at 2,000 points.
